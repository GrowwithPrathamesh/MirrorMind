# MirrorMind

MirrorMind is a web-based virtual classroom developed as my **Diploma Final Year Capstone Project**. The project was developed by a team of five, where I worked as the **Team Leader and Backend Developer**.

The main idea behind MirrorMind was to build an online classroom system with features such as virtual classes, attendance automation, and student engagement monitoring.

## Features

* User registration and login
* Email OTP verification
* Separate Teacher and Student interfaces
* Class creation and scheduling
* Join and leave virtual classes
* Video and audio communication
* Real-time chat
* Screen sharing
* Mute and unmute
* Face recognition based attendance
* Attendance stored in the database
* Student emotion detection
* Student engagement monitoring for teachers

## AI Implementation

DeepFace was used for facial analysis and emotion recognition.

The project uses **pretrained DeepFace models**. We integrated the existing models into the application instead of training a new model from scratch.

## Project Structure

The application mainly consists of two sides:

**Teacher Side**

* Manage and schedule classes
* Conduct virtual classes
* Monitor attendance
* View student emotion and engagement information

**Student Side**

* Register and login
* Verify account using email OTP
* View scheduled classes
* Join virtual classes
* Participate using video, audio, chat and screen sharing

## Project Objective

The objective of MirrorMind was to make online classroom management easier by combining normal virtual classroom features with automated attendance and student monitoring.

Instead of only providing video communication, the system also provides teachers with attendance and student engagement related information during online classes.
