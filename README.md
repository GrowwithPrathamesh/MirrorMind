# MirrorMind

### AI-Powered Virtual Classroom with Face Recognition Attendance and Student Engagement Monitoring

MirrorMind is an **AI-powered virtual classroom platform** developed as a **Final Year Capstone Project during my Diploma in Computer Engineering**.

The platform combines virtual classroom functionality with **face-recognition-based attendance**, **student emotion detection**, and **student engagement monitoring** to provide teachers with better insights into online classroom participation.

## 🚀 Features

### 🔐 Authentication & User Management

* User registration
* Login system
* Email OTP verification
* Secure user authentication
* Separate Teacher and Student access

### 🏫 Virtual Classroom

* Create and schedule classes
* Join scheduled classes
* Video calling
* Audio communication
* Real-time chat
* Screen sharing
* Mute / Unmute
* Join / Leave meeting

### 📊 Attendance & Monitoring

* Face recognition-based attendance
* Automatic attendance recording
* Attendance data stored in database
* Student emotion detection
* Student engagement monitoring
* Teacher-side monitoring dashboard

### 👨‍🏫 Teacher Dashboard

* Manage classes
* Schedule classes
* Monitor students
* View attendance
* Monitor student emotions and engagement

### 👨‍🎓 Student Dashboard

* View scheduled classes
* Join classes
* Participate through video and audio
* Chat and screen sharing
* Attendance through face recognition

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Face Analysis:** DeepFace
* **Development:** Git & GitHub

## 🧠 AI Components

MirrorMind uses **DeepFace** for facial analysis and emotion recognition.

The project uses **pretrained DeepFace models** for facial analysis and emotion recognition rather than training a new model from scratch.
